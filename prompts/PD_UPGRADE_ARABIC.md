# الجزء 1: متطلبات الترقية الشاملة (17 قسم) — منقول حرفياً
# ═══════════════════════════════════════════════════════

المطلوب: تنفيذ ترقية شاملة وجذرية للمنصة بحيث تدعم بشكل كامل جميع القدرات التالية: المطابقة الحرفية 100% للتصميمات، التفريغ الاحترافي من الصور وPDF، والتعريب الاحترافي عالي الدقة. التنفيذ يجب أن يكون فعلياً بالكامل بكود حقيقي يعمل في بيئة الإنتاج، وليس مجرد هياكل كود أو وظائف وهمية أو محاكاة. يجب أن تكون جميع المكونات قابلة للتشغيل الفعلي ومتصلة ببعضها ضمن نظام متكامل.

أولاً: الهدف العام للنظام
بناء نظام ذكاء اصطناعي متعدد الطبقات قادر على:

- تحليل الصور وملفات PDF والوثائق بشكل كامل
- استخراج البنية والتصميم والمحتوى بدقة كاملة
- إعادة إنشاء الملفات المختلفة بنفس التصميم حرفياً
- دعم التعريب الاحترافي الكامل مع الحفاظ على التصميم
- تنفيذ تفريغ نصوص وبيانات من الصور وPDF بدقة عالية جداً
- إعادة توليد الملفات بنفس التنسيق والبنية

يجب أن يعمل النظام عبر خط معالجة كامل يبدأ من الإدخال وينتهي بتوليد ملفات نهائية قابلة للاستخدام في Excel وPowerPoint وDashboards وReports.

ثانياً: متطلبات المطابقة الحرفية للتصميم (Pixel-Perfect Reconstruction)

تنفيذ محرك كامل قادر على تحويل أي صورة أو لقطة شاشة إلى ملف مطابق لها حرفياً.

يجب أن يتضمن النظام:

- محرك تحليل بصري للوثائق
- استخراج كامل لتخطيط الصفحة Layout
- استخراج الخطوط والألوان والحدود والظلال
- استخراج الجداول والرسوم البيانية
- استخراج مكونات الواجهة ولوحات التحكم
- استخراج الأيقونات والعناصر المتجهة
- استخراج الطبقات وترتيبها

ثم تحويل كل ذلك إلى تمثيل داخلي موحد (Intermediate Representation).

بعد ذلك يجب أن يقوم النظام بإعادة بناء الملف النهائي عبر:

- توليد PowerPoint
- توليد Excel
- توليد تقارير
- توليد Dashboards

ثم إعادة تصيير الملف الناتج كصورة ومقارنته بالصورة الأصلية عبر مقارنة البكسل.

يجب تنفيذ حلقة تحسين تلقائية: Generate → Render → Compare → Optimize → Repeat حتى الوصول إلى تطابق بصري كامل.

يجب تنفيذ:

- Pixel comparison
- SSIM comparison
- LPIPS comparison
- Subpixel alignment correction
- Layout constraint solving

ولا يتم قبول النتيجة حتى تصبح المطابقة البصرية كاملة.

ثالثاً: محرك فهم الوثائق (Document Intelligence)

تنفيذ نظام قادر على فهم الوثائق كاملة.

يشمل ذلك:

- تصنيف نوع الوثيقة
- تحليل تخطيط الصفحة
- كشف الأعمدة
- كشف الفقرات والعناوين
- كشف الجداول
- كشف الرسوم البيانية
- كشف الصور
- كشف القوائم
- كشف النماذج

يجب أن يدعم:

- الوثائق متعددة الأعمدة
- الوثائق الطويلة
- الوثائق المختلطة
- المستندات الحكومية
- التقارير المالية

رابعاً: نظام OCR احترافي

يجب تنفيذ محرك OCR متعدد اللغات يدعم العربية والإنجليزية بدقة عالية.

المتطلبات:

- استخراج الحروف
- استخراج الكلمات
- استخراج الأسطر
- استخراج الفقرات
- استخراج مواقع النصوص
- استخراج حجم الخط
- استخراج وزن الخط
- استخراج المسافات بين الأحرف

يجب أن يدعم:

- النصوص المختلطة عربي / إنجليزي
- النصوص داخل الجداول
- النصوص داخل الرسوم
- النصوص داخل الصور

بعد استخراج النص يجب تمريره عبر نظام تصحيح لغوي يعتمد على نماذج لغوية لتصحيح أخطاء OCR.

خامساً: معالجة اللغة العربية

تنفيذ دعم كامل للغة العربية يشمل:

- اتجاه النص RTL
- تشكيل الحروف العربية
- دعم Ligatures
- دعم Kashida
- دعم التشكيل
- معالجة علامات الترقيم العربية

ويجب استخدام محرك طباعة يدعم OpenType ومعالجة النصوص العربية بشكل صحيح.

سادساً: استخراج الجداول

تنفيذ نظام متكامل لاستخراج الجداول من الصور وPDF.

يجب أن يكتشف:

- الصفوف
- الأعمدة
- الخلايا
- الخلايا المدمجة
- رؤوس الجداول
- الحدود
- المحاذاة

ويجب إعادة بناء الجداول في: Excel و CSV و JSON و DataFrames مع الحفاظ على البنية الأصلية.

سابعاً: تحليل الرسوم البيانية

يجب بناء محرك قادر على:

- تحديد نوع الرسم البياني
- استخراج المحاور
- استخراج البيانات
- استخراج الأسطورة
- استخراج القيم
- استخراج الألوان

ثم تحويل الرسم البياني إلى بيانات منظمة قابلة لإعادة البناء.

ثامناً: استخراج واجهات الداشبورد

يجب تنفيذ نظام قادر على تحليل:

- KPI cards
- charts
- tables
- filters
- dropdowns
- slicers

ثم إعادة بناء لوحة التحكم.

تاسعاً: التعريب الاحترافي

تنفيذ نظام ترجمة احترافي يعتمد على:

- الترجمة العصبية
- الترجمة السياقية
- إدارة المصطلحات
- ذاكرة الترجمة
- مراجعة الجودة اللغوية

المتطلبات:

- ترجمة دقيقة حسب السياق
- الحفاظ على المصطلحات
- الحفاظ على المعنى
- الحفاظ على التنسيق
- الحفاظ على التخطيط

يجب أن يتم التعريب دون كسر التصميم.

عاشراً: الحفاظ على التصميم أثناء الترجمة

تنفيذ محرك يضمن:

- إعادة ضبط طول النص
- التفاف النص
- إعادة توزيع العناصر
- منع تجاوز النص للحاويات

مع الحفاظ على التخطيط العام.

الحادي عشر: نظام مراجعة الجودة

يجب تنفيذ نظام تحقق تلقائي يقوم بـ:

- كشف النصوص المفقودة
- كشف التكرار
- كشف الأخطاء اللغوية
- كشف أخطاء الترجمة
- كشف مشاكل التخطيط
- كشف النصوص الخارجة عن الحاويات

الثاني عشر: إعادة بناء الملفات

يجب أن يتم توليد الملفات النهائية بصيغ: PPTX و XLSX و DOCX و HTML و PDF و JSON

مع الحفاظ على: الخطوط والألوان والأحجام والمسافات والطبقات والتخطيط.

الثالث عشر: دعم PDF

يجب دعم جميع أنواع PDF:

- searchable PDF
- scanned PDF
- hybrid PDF

ويجب استخراج: النص والصور والرسومات المتجهة والخطوط والطبقات.

الرابع عشر: تحسين جودة الصور

قبل OCR يجب تنفيذ:

- إزالة الضوضاء
- تصحيح الانحراف
- تحسين التباين
- إزالة التشويش
- رفع دقة الصورة

الخامس عشر: بنية التنفيذ

يجب تنفيذ النظام عبر Pipeline متكامل:

Input → Preprocessing → Layout Analysis → OCR → Structure Parsing → Semantic Analysis → Reconstruction → File Generation → Validation

السادس عشر: متطلبات التنفيذ الصارمة

يجب الالتزام بما يلي:

- تنفيذ جميع المكونات بكود حقيقي قابل للتشغيل
- منع استخدام أي placeholder functions
- منع استخدام mock services
- منع استخدام pseudo implementations
- جميع الوظائف يجب أن تكون مرتبطة بمحركات حقيقية
- جميع العمليات يجب أن تعمل فعلياً في بيئة الإنتاج

السابع عشر: معايير القبول

لا يعتبر التنفيذ مكتملاً إلا إذا:

- تم استخراج النصوص بدقة عالية
- تم استخراج البنية الكاملة للوثيقة
- تم إعادة بناء الملفات بنفس التنسيق
- تم تحقيق المطابقة البصرية الكاملة
- تم تنفيذ التعريب دون كسر التصميم
- تم تنفيذ جميع الخدمات ضمن نظام واحد متكامل

# الجزء 2: برومت ترقية الخدمات الحالية — منقول حرفياً
# ═══════════════════════════════════════════════════════

أنت المهندس المسؤول عن تطوير المنصة الحالية. المطلوب منك تنفيذ ترقية شاملة للخدمات الموجودة بالفعل داخل النظام. هذه ليست مهمة إنشاء نظام جديد أو محركات جديدة من الصفر. المنصة تحتوي بالفعل على خدمات تعمل في مجالات تحليل البيانات، إنشاء التقارير، إنشاء الداشبورد، التعامل مع ملفات Excel، توليد العروض التقديمية، وبعض قدرات OCR والترجمة. المطلوب هو تطوير هذه الخدمات الحالية ورفع مستواها إلى أقصى مستوى احترافي ممكن عبر تحسين المكونات الموجودة ودمج القدرات المتقدمة داخلها.

ممنوع إنشاء نظام منفصل أو إعادة بناء المنصة بالكامل خارج بنيتها الحالية. جميع التحسينات يجب أن تكون امتداداً للخدمات الموجودة حالياً وأن يتم دمجها مباشرة في البنية الحالية للمنصة.

يجب أن يتم التنفيذ بكود حقيقي يعمل في بيئة الإنتاج. لا يُسمح باستخدام وظائف وهمية أو placeholder أو mock services أو pseudo code. أي مكون تضيفه يجب أن يكون قابلاً للتشغيل الفعلي ومتصلاً بالخدمات الحالية للمنصة.

الهدف من الترقية: أن تصبح الخدمات الحالية قادرة على:
1. المطابقة الحرفية للتصميمات (Pixel Perfect Reconstruction)
2. التفريغ الاحترافي من الصور وملفات PDF
3. التعريب الاحترافي المتقدم مع الحفاظ على التصميم

قواعد التنفيذ الإلزامية:
- جميع التحسينات امتداد للخدمات الموجودة
- ممنوع إنشاء نظام منفصل أو منصة جديدة
- يجب دمج جميع القدرات داخل الخدمات الحالية
- يجب تنفيذ كل شيء بكود حقيقي يعمل
- ممنوع استخدام placeholder أو mock أو pseudo implementations
- كل المكونات قابلة للتشغيل في بيئة الإنتاج

طريقة التنفيذ:
- ابدأ مباشرة بتحليل الخدمات الحالية
- حدد أين تُضاف التحسينات داخل الكود الموجود
- طوّر المكونات الحالية بدلاً من استبدالها
- ابدأ التنفيذ فوراً ولا تقدم شرحاً نظرياً
