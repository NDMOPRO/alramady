# ⛔ PI — تدقيق الربط الشامل: كل مواصفة ← صفحة ← اختبار ⛔
# هذا البرومت يتحقق أن كل مواصفة من المواصفات مربوطة فعلياً بصفحة واجهة مستخدم
# أي مواصفة غير مرتبطة ← يربطها فوراً
# أي صفحة ناقصة ← يبنيها فوراً
# أي زر غير موجود ← يضيفه فوراً

---

أنت Claude Code تعمل في وضع **Spec-to-Page Auditor + Builder**.

**مهمتك الوحيدة:**
لكل مواصفة من المواصفات → تأكد أنها مرتبطة بصفحة → إذا لم تكن مرتبطة → اربطها الآن.

**المسار:** `C:\DATA_AI\rasid`
**الدخول:** admin / 1500

---

## ⛔ القانون:
```
◆ لا تتخطّ أي مواصفة — كل سطر يبدأ بـ - في ملفات البرومتات = مواصفة يجب التحقق منها
◆ كل مواصفة يجب أن تكون: (1) كود حقيقي + (2) route API + (3) صفحة/زر/تبويب في الواجهة + (4) تعمل فعلياً
◆ إذا أي شرط مفقود → أضفه الآن — لا تسجّله كملاحظة — نفّذه
◆ لا mock — لا TODO — لا placeholder
```

# ═══════════════════════════════════════════════════════
# المرحلة 1: تدقيق صفحة البيانات /data
# ═══════════════════════════════════════════════════════

## اقرأ prompts/P01_DATA_ENGINE.md (أو البرومت المقابل)
## لكل بند (كل سطر يبدأ بـ -)، تحقق:

```
لكل بند:
  1. هل يوجد route API يخدم هذا البند؟
     → إذا لا: أنشئ الـ route
  2. هل يوجد عنصر في صفحة /data يعرض أو يُفعّل هذا البند؟
     → إذا لا: أضف زر/تبويب/قسم في الصفحة
  3. هل يعمل فعلياً عند الضغط؟
     → إذا لا: أصلح الربط
```

## المواصفات التي يجب التحقق من ربطها بصفحة /data:

```
□ رفع أي نوع ملف (Excel, CSV, JSON, PDF, صور, مضغوطة, مجلدات, روابط) ← زر رفع + drag-and-drop
□ OCR تلقائي للصور ← يعمل عند رفع صورة
□ ربط مع 50+ مصدر خارجي ← تبويب "الموصلات" أو زر "ربط مصدر"
□ مزامنة دورية ← إعدادات المزامنة في الصفحة
□ تصنيف تلقائي لنوع الملف ← يظهر بجانب كل ملف بعد الرفع
□ فهرسة تلقائية ← تظهر في المعاينة
□ اكتشاف الأعمدة والأنواع تلقائياً ← تبويب "الأعمدة"
□ اكتشاف الجداول غير المنسقة ← يعمل عند الرفع
□ ربط ملفات عبر أعمدة مشتركة ← تبويب "العلاقات" أو السحب والإفلات
□ اكتشاف الأعمدة المتشابهة ← يظهر في مركز الأعمدة
□ دمج عمود من ملف مع عمود آخر ← السحب والإفلات
□ فصل عمود ← زر في مركز الأعمدة
□ دمج جداول ← زر أو سحب
□ تقسيم ملف ضخم ← زر "تقسيم"
□ إزالة التكرار ← زر في تبويب "تنظيف"
□ كشف القيم المفقودة ← يظهر تلقائياً
□ درجة جودة من 100 ← مؤشر بصري لكل ملف
□ إعادة هيكلة بزر واحد ← زر "إعادة هيكلة"
□ Canvas بصري (سحب ملفات وأعمدة) ← تبويب "Canvas"
□ الوضع السهل ← زر رئيسي "تحليل ذكي"
□ الوضع المتقدم ← أيقونة إعدادات أو تبويب خاص
□ بث تدريجي للجداول الضخمة ← يعمل تلقائياً
□ Lakehouse (DuckDB + Arrow + Iceberg + ClickHouse) ← يعمل في الخلفية
□ Dataset Registry ← تبويب "مجموعات البيانات"
□ Semantic Layer (Metric + Dimension Registry) ← تبويب "الطبقة الدلالية"
□ Relationship Graph ← تبويب "العلاقات" مع رسم بياني
```
